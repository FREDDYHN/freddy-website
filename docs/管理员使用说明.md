# 管理员使用说明 — 包装法授权代表后台

> 适用对象：福瑞笛（FREDDY）内部管理员
> 后台入口：`www.freddy-epr.com/admin`（需登录）

---

## 一、登录

1. 打开 `www.freddy-epr.com/login`，输入管理员账号与密码。
2. 登录后自动跳转「**项目管理**」后台。

| 项 | 值 |
|---|---|
| 管理员账号 | admin@freddy-epr.com |
| 默认密码 | Admin918 |

> ✅ 多位管理员可**共用同一个账号**同时登录在线，互不干扰（不会互相踢下线）。

> ⚠️ 请登录后及时修改默认密码（可联系开发人员重置）。

---

## 二、统计总览

登录后顶部显示四项核心指标：**总客户** / **活跃合同** / **待付款**（红色高亮）/ **年收入 €**。

右侧：**📥 导出 CSV**（导出全部客户清单）、**EUR/CNY 汇率**（「调」手动 /「↻」自动抓取）。

---

## 三、合同管理

后台按服务类型分三个标签页：📦 **包装法 AR**（basic/standard/premium）、🔌 **WEEE**、🔋 **电池法**。

筛选与搜索：**状态筛选** / **🔔 待办**（待付款、有上传待审核）/ **含待验证** / **搜索框**（公司/手机号/联系人/法人/合同号后4位）/ **重置**。

### 合同列表（7 列）

| 列 | 含义 |
|---|---|
| 基本信息 | 公司名 + 合同编号（LTO-AR-YYYY-NNNN）+ 套餐 |
| 服务周期 | 合同起止日期 |
| 往年缴费凭证 | 客户上传的往年缴费凭证（归档查阅，点「📄」下载） |
| 授权代表年费 | 套餐年费 € + 付款凭证 |
| 预申报费 | 预估回收费用 + 「已预申报」状态 + 凭证 |
| 年终结算 | 按实际量结算的回收费用 + 凭证 |
| 账户管理 | 状态、LUCID、重置密码、回签、垃圾/删除等操作 |

点击**公司名**可查看客户完整信息（联系人、地址、LUCID 号等）。

## 四、核心操作

### 1. 审核付款凭证（激活合同）

客户转账后上传凭证，管理员在对应费用列点「📄」**下载核对**，到账后点「**确认**」：

- **年费凭证**（授权代表年费列）→ 确认后合同「已激活」并自动开具**双语 PDF 发票**。
- **预申报费 / 年终结算凭证** → 确认后更新对应缴费状态。

### 2. 审核「已预申报」标记（新增）

> 适用场景：客户已在其他渠道完成本年度预申报并缴费，无需向本平台缴纳预申报费。客户会在 Dashboard「预申报费」列点「**我已预申报**」并上传缴费凭证。

1. 客户标记「我已预申报」→ 上传预申报缴费凭证。
2. 管理员在「预申报费」列看到黄色「**已预申报·待审核**」及凭证链接。
3. 核对凭证后点「**确认**」→ 变为绿色「**已预申报 ✓**」。
4. 此操作**不影响付款**（不核销任何收款）；凭证不合规可删除/驳回，客户可重新标记。

### 3. 回签（上传盖章合同）

客户上传盖章合同后：账户管理列 → **回签上传** → 选择 LIVANTO 盖章后的合同 → 客户即可「下载终版」。

### 4. 回收费设置

对某合同设置「**预缴**」或「**年终结算**」金额（€），保存后客户端可见；客户转账上传凭证后，管理员在对应列点「确认」核销。

### 5. 重置客户密码

账户管理列 → **重置密码** → 系统生成 8 位随机新密码 → 告知客户并提醒登录后修改。

### 6. 标记垃圾 / 删除

- **标记垃圾**：将可疑合同标为垃圾（识别虚假订单）。
- **删除合同**：⚠️ 不可逆！将删除合同及全部支付/上传/通知记录，删除前务必确认。

## 五、常见工作流

**新客户签约到激活的完整流程：**

1. 客户在线签约 → 合同进入「待验证」
2. 客户邮箱验证 → 合同变为「待付款」
3. 客户转账并上传凭证 → 管理员**审核凭证确认** → 合同「已激活」并自动开票
4. 客户生成并上传盖章合同 → 管理员**回签** → 客户下载终版
5. 如有回收费用，管理员**设置回收费**并审核凭证

**客户咨询密码问题：** 后台 → 账户管理 → 重置密码 → 告知新密码
