# 管理员使用说明 — 包装法授权代表后台

> 适用对象：福瑞笛（FREDDY）内部管理员
> 后台入口：`www.freddy-epr.com/admin`（需登录）

---

## 一、登录

1. 打开 `www.freddy-epr.com/login`
2. 输入管理员账号与密码
3. 登录后自动跳转「**项目管理**」后台

| 项 | 值 |
|---|---|
| 管理员账号 | admin@freddy-epr.com |
| 默认密码 | Admin918 |

> ⚠️ 请登录后及时修改默认密码（可联系开发人员重置）。

---

## 二、统计总览

登录后顶部显示四项核心指标：

- **总客户**：平台注册客户总数
- **活跃合同**：状态为"已激活"的合同数
- **待付款**：待确认到账的合同数（红色高亮）
- **年收入 €**：已支付合同年费合计

右侧还有：
- **📥 导出 CSV** 按钮（导出全部客户清单）
- **EUR/CNY 汇率**显示，可点「**调**」手动调整，或「**↻**」从数据源自动抓取

---

## 三、合同管理

后台按服务类型分三个标签页：

| 标签 | 对应服务 |
|------|----------|
| 📦 包装法 AR | 包装法授权代表（basic/standard/premium） |
| 🔌 WEEE | 电子电气设备法 |
| 🔋 电池法 | 电池法 BattG |

> 标签旁数字为该类合同+申请的总数。

### 筛选与搜索

- **状态筛选**：全部 / 已激活 / 待付款 / 待验证 / 已签署 / 已过期
- **🔔 待办**：筛选出需要处理的项目（待付款、有上传待审核、已签未回签）
- **含待验证**：勾选后显示"待验证"状态的合同（默认隐藏）
- **搜索框**：按公司 / 手机号 / 联系人 / 法人 / 合同号后 4 位搜索
- **重置**：清空所有筛选条件

### 合同列表列说明

| 列 | 含义 |
|---|---|
| 基本信息 | 公司名 + 合同编号（LTO-AR-YYYY-NNNN）+ 套餐 |
| 状态 | 待验证 / 待付款 / 已激活 / 已签署 / 已过期 |
| LUCID | ✅ 已授权（客户已在 LUCID 指定 LIVANTO）/ ⚠️ 待授权 |
| 服务周期 | 合同起止日期 |
| 授权代表年费 | 套餐年费 € |
| 预申报费 | 包装预申报的预估回收费用 |
| 年终结算 | 按实际量结算的回收费用 |
| 账户管理 | 各项操作按钮 |

点击**公司名**可查看客户完整信息（联系人、地址、LUCID 号等）。

## 四、账户管理操作

### 1. 确认支付（激活合同）

客户付款到账后：
1. 在对应合同的「账户管理」列点击**确认支付**
2. 系统将支付标记为已付，合同状态自动变为「已激活」

### 2. 回签（上传盖章合同）

客户上传盖章合同后，管理员完成 LIVANTO 回签：
1. 点击「账户管理」列的**回签上传**
2. 选择 LIVANTO 盖章后的合同文件上传
3. 客户端即可「下载终版」

### 3. 回收费设置

针对某合同设置回收费用：
- **预缴**：签约时预收的回收费用
- **年终结算**：按实际申报量结算的费用
- 输入金额（€）后保存，客户端可见

### 4. 重置客户密码

客户忘记密码时：
1. 点击「账户管理」列的**重置密码**
2. 确认后系统生成 8 位随机新密码
3. 将新密码告知客户，提醒其登录后尽快修改

### 5. 标记垃圾 / 删除

- **标记垃圾**：将可疑合同标为垃圾（用于识别虚假订单）
- **删除合同**：⚠️ 不可逆！将删除合同及其所有支付、上传、通知记录。删除前请务必确认。

---

## 五、导出客户清单

点击顶部「**📥**」按钮，导出全部客户 CSV 文件（含公司、联系人、邮箱、电话、LUCID 号、合同、年费等），可直接用 Excel 打开。

---

## 六、汇率管理

- 当前汇率用于人民币预估（页面上「≈ ¥XX」的换算）。
- 点击「**调**」手动输入汇率。
- 点击「**↻**」从数据源自动抓取最新汇率。

---

## 七、待验证合同

客户提交签约后，合同先进入「**待验证**」状态（尚未完成邮箱验证）。
- 默认在列表中**隐藏**，勾选「**含待验证**」后可见。
- 待验证合同不计入活跃客户统计。
- 客户完成邮箱验证后，状态自动变为「待付款」。

---

## 八、常见工作流

**新客户签约到激活的完整流程：**

1. 客户在线签约 → 合同进入「待验证」
2. 客户邮箱验证 → 合同变为「待付款」
3. 客户支付 → 管理员**确认支付** → 合同「已激活」
4. 客户生成并上传盖章合同 → 管理员**回签** → 客户下载终版
5. 如有回收费用，管理员**设置回收费**

**客户咨询密码问题：** 后台 → 账户管理 → 重置密码 → 告知新密码
