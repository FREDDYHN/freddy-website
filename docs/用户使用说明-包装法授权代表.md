## 三、在线签约流程

### 第 1 步：填写委托方信息

打开 `www.freddy-epr.com` → 点击「**立即签约**」或「**包装法授权代表**」，进入签约向导。

按提示填写以下信息（带 * 为必填）：

- **公司名称**（中文 *、英文或拼音 *）
- **注册地址**（中文 *、英文或拼音）
- **统一社会信用代码 / 税号**（如有）
- **法定代表人**（中文 *、拼音 *）
- **联系人**（中文 *、拼音 *）
- **手机号** *（选择区号后填写号码）
- **微信号** *
- **电子邮箱** *（用于登录，提交后将收到验证邮件）

### 第 2 步：包装预申报

页面列出 **8 种包装材料**（玻璃、纸/纸板、黑色金属、铝、塑料、饮料纸盒、其他复合包装、其他），逐行填写：

- **类别**（B2C 或 B2B，下拉选择）
- **预估年量**（kg/年，直接输入数字）
- **产品举例**（可选，如"手机壳"）

**未使用的材料留空即可**，无需逐条添加；填完直接点「**下一步**」。系统会按填写的量自动估算回收费用。

### 第 3 步：信息确认并提交

核对全部信息与预估年费，确认无误后点击「**确认无误，创建合同**」。

提交成功后，页面提示「合同已创建，请查收验证邮件」。

1. 查收系统发送的**验证邮件**（邮件标题含"请设置登录密码"）。
   - 若未收到，请检查垃圾邮件箱。

2. 点击邮件中的链接，设置**登录密码**（至少 6 位字符）。

3. 设置成功后自动登录，进入 **Dashboard（合规面板）**。

## 六、支付

本服务分**三次付款**，每次付款的金额与状态都可在 Dashboard 的「**📊 缴费明细**」中查看：

### 第 1 次：授权代表年费（签约时）

- **金额**：按套餐固定（基础 €29 / 标准 €49 / 高级 €79）
- **时间**：签约后立即支付，到账后合同**激活**、服务生效
- **方式**：**微信支付** 或 **银行转账**

### 第 2 次：回收费预缴（按预估年量）

- **金额**：按您第 2 步填写的**预估年量** × 各材料单价计算（有最低起步费）
- **时间**：合同激活后，管理员核定金额并通知您缴纳
- **方式**：**银行转账**，转账后上传付款凭证

### 第 3 次：年终结算（按实际年量）

- **时间**：次年 3 月 1 日前申报**实际用量**后结算
- **规则**：
  - 实际量 ≈ 预估量 → 无需补退
  - 实际量 > 预估量 → **补缴**差额（超出预估量 20% 以上时，超出部分加收 20%）
  - 实际量 < 预估量 → **退款**（最多退预估费的 10%）
  - 未按时申报 → 按预估量结算，不予退款
- **方式**：**银行转账**（补缴）/ 原路退回（退款）

> 每次付款后，请在 Dashboard 上传付款凭证，管理员确认到账后更新缴费状态。
